# Tests

This directory contains tests for the BasicVSR++ project.

## Test Files

- **`test_basic.py`**: Basic functionality tests (imports, model building, etc.)
- **`test_imports.py`**: Import tests
- **`test_training.py`**: Training functionality tests
- **`test_deformconv.py`**: Deformable convolution tests
- **`generate_test_data.py`**: Script to generate test dataset for CI

## Running Tests Locally

### 1. Install Dependencies

```bash
pip install -r requirements.txt
```

### 2. Run Basic Tests

```bash
# Test imports
python tests/test_imports.py

# Test basic functionality (requires dependencies)
python tests/test_basic.py
```

### 3. Run Training Tests

```bash
# Generate test data first
python tests/generate_test_data.py

# Run training tests
python tests/test_training.py

# Or run actual training with test config
python tools/train.py configs/test_ci.py
```

## CI Tests

The project uses GitHub Actions for continuous integration. The workflow is defined in `.github/workflows/test.yml`.

### What Gets Tested

1. **Import Tests**: Verify all modules can be imported
2. **Model Building**: Test that models can be built from configs
3. **Training**: Run 2-3 iterations of training on CPU
4. **Resume Training**: Test checkpoint loading and resume
5. **Inference**: Test inference functionality

### CI Configuration

The CI uses a minimal configuration (`configs/test_ci.py`) that is optimized for fast testing:
- Very small model (8 channels, 1 block)
- Small images (64x64)
- Few frames (5 frames)
- CPU-only (no GPU)
- Minimal iterations (2-10)

### Running CI Tests Locally

To run the same tests that CI runs:

```bash
# Generate test data
python tests/generate_test_data.py

# Run training test (2 iterations)
python tools/train.py configs/test_ci.py \
  --cfg-options train_cfg.max_iters=2 \
  default_hooks.checkpoint.interval=1

# Test resume
python tools/train.py configs/test_ci.py \
  --resume work_dirs/test_ci/iter_2.pth \
  --cfg-options train_cfg.max_iters=3
```

## Test Data

Test data is automatically generated by `generate_test_data.py` and consists of:
- Small synthetic videos (64x64 resolution)
- 10 frames per video
- Simple color patterns for visual variation
- Metadata files in JSON format

The test data structure:
```
data/test_ci/
├── train/
│   ├── test_video_000.mp4
│   ├── test_video_000_metadata.json
│   ├── test_video_001.mp4
│   └── test_video_001_metadata.json
└── val/
    ├── test_video_000.mp4
    └── test_video_000_metadata.json
```

## Troubleshooting

### Tests Fail with "No module named..."

Make sure all dependencies are installed:
```bash
pip install -r requirements.txt
```

### Tests Fail with "Test data not found"

Generate test data first:
```bash
python tests/generate_test_data.py
```

### Out of Memory on CI

The CI configuration is already minimal. If issues persist, reduce:
- `mid_channels` in model config
- `lq_size` (image size)
- `num_frame` (number of frames)

### Tests Pass Locally but Fail on CI

Check:
- Python version (CI uses 3.10)
- PyTorch installation (CI uses CPU-only version)
- File paths (use relative paths from project root)
